当前项目要从失败原型变成优秀 Agent 服务，先要确定第一阶段重心。你可以点击一个方向，也可以直接在终端补充你的判断。

优先修核心循环、权限、模型适配、持久化、测试和 CLI 契约，再做高级交互体验。

先做可部署服务

优先做 API server、worker 生命周期、任务队列、插件、多会话并发执行，而不是先抛光交互界面。

我的建议

第一阶段选 A：核心底座优先。当前代码不是“差一点 UI”，而是核心 loop、权限、provider、session、测试都不稳。先稳住底座，再从 B 和 C 吸收优秀能力。
